# Sources and licences

Every skill ends with a footer naming its upstream and snapshot. This file is the full ledger: what was taken, from which version, under which licence, and what was deliberately left out. Each upstream was security-vetted (hooks, installers, network calls, telemetry) before anything was distilled; nothing here installs or runs upstream code.

Rule used throughout: distil the few rules that matter, rewrite them to fit together, keep attribution, then uninstall the original so two copies never compete for the same trigger.
